# Network Administration & Infrastructure Portfolio

Welcome to my network engineering and system administration portfolio. This repository documents hands-on enterprise network topologies, routing/switching configurations, and infrastructure labs built during my Cisco CCNA preparation and system administration studies.

## 🛠️ Technical Competencies
* **Routing & Switching:** VLANs, Trunking (802.1Q), Inter-VLAN Routing, Spanning Tree Protocol (STP), DHCP DORA process.
* **Protocols:** CDP, LLDP, OSPF, TCP/IP stack configuration.
* **Operating Systems & Tools:** Cisco Packet Tracer, Linux (Arch Linux CLI, Package Management, Dependency Resolution), Git/GitLab version control.

## 📂 Featured Laboratory Projects

### Project 1: Multi-VLAN Enterprise Campus Network
* **Objective:** Design and segment a multi-department enterprise network to isolate broadcast domains and enforce security boundaries.
* **Key Implementation Details:**
  * Configured Cisco switches and routers using `CLI` commands.
  * Implemented VLAN segmentation (HR, Engineering, Management) and trunking links.
  * Verified inter-VLAN routing and end-to-end host connectivity via ICMP ping tests and DHCP address assignment.
* **Files:** Located in `/projects/enterprise-vlan-campus/` *(Coming soon)*

### Project 2: Dynamic Routing & Redundancy Topology
* **Objective:** Build a fault-tolerant multi-router network layout utilizing redundant paths and dynamic routing protocols.
* **Key Implementation Details:**
  * Configured multi-router topologies using Cisco 3745 nodes and modular interface cards.
  * Configured routing tables and verified loop prevention mechanisms.
* **Files:** Located in `/projects/redundant-routing-lab/` *(Coming soon)*

## 🚀 How to View and Test Labs
1. Download [Cisco Packet Tracer](https://www.netacad.com/).
2. Clone this repository or download individual `.pkt` simulation files from the project folders.
3. Open the `.pkt` files to inspect the live running configurations, topology layouts, and routing tables.
